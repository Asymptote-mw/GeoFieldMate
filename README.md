# GeoFieldMate

GeoFieldMate is a mobile app that helps geologists and geological engineers
collect, organize, and export field data. It replaces paper notebooks with a
fast, offline-capable tool built for use in the field.

## Features

- **GPS location tagging** for observations and sample points
- **Lithology logging** with structured, consistent entries
- **Offline storage** using SQLite, so you can work without network coverage
- **AI assistance** powered by Google Gemini
- **PDF and CSV export** for reports and further analysis in GIS or spreadsheets

## Tech Stack

- Flutter / Dart
- SQLite (local database)
- Google Gemini API
